# About Page Kit

Use this skill when the user wants an about page for a brand, store, or product site.

## What to do
- match the existing site’s design system
- reuse the same fonts, spacing, colors, and section rhythm
- build a story section, values/process section, and team section only if content exists
- keep the page visually consistent with the landing page instead of introducing a different look

## Important
- do not invent values, team members, or story content that was not provided
- if there is no existing site, choose a restrained pairing from the brand vibe docs
- make the page feel like the same site, not a separate disconnected page
